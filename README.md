# Tome of Vengeance

Remember every enemy player you've slain and every foe who slew you, in an open-book PvP journal.

Scaffold in development: storage is implemented; tracking, UI and commands are not yet available.

## Install

Copy `TomeOfVengeance/` into your client's `Interface/AddOns/` directory (for example, `World of Warcraft/_retail_/Interface/AddOns/` or `_forever_/Interface/AddOns/`). Restart the client or enable the addon at character selection.

## Usage

Planned command: `/tov`. The `/tome` alias is dropped because [DungeonTome](https://www.curseforge.com/wow/addons/dungeontome-forever) and [Chronicle Tome](https://www.curseforge.com/wow/addons/chronicle-tome) already document it.

CurseForge and Wago slash-clash searches on 2026-11-07 found no documented `/tov` conflict. Search indexing is incomplete; this is not a guarantee of availability.
